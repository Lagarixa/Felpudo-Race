# Felpudo-Race
🐦 Felpudo Race

Felpudo Race é um jogo desenvolvido por Maria de Novais Oliveira e Yasmin Freitas como projeto para a disciplina de Programação de Jogos.

Inspirado no estilo de Flappy Bird, o jogo desafia o jogador a controlar um pássaro em uma missão para salvar sua amada. Para alcançar seu objetivo, será necessário sobreviver a 20 segundos de ataques de hordas de inimigos, desviando dos obstáculos por meio de saltos.

Como jogar
O objetivo principal é sobreviver durante 20 segundos, desviando dos inimigos que aparecem pelo caminho.

Utilize o controle abaixo para movimentar o personagem:
Clique esquerdo do mouse	Faz o personagem pular

🐦 Felpudo Race

Felpudo Race is a game developed by Maria de Novais Oliveira and Yasmin Freitas as a project for the Game Programming course.

Inspired by the gameplay style of Flappy Bird, the game challenges players to control a bird on a mission to rescue his beloved. To achieve this goal, players must survive 20 seconds of enemy attacks, dodging obstacles by jumping.

How to Play
The main objective is to survive for 20 seconds while avoiding the enemies that appear along the way.

Use the following control to move the character:
Left mouse button	aakes the character jump
